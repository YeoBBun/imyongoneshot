# 임용 국어 공부

임용시험(국어교육) 대비용 학습 웹앱 모음입니다. 첫 화면에서 과목을 고르면 해당 앱으로 이동합니다.

| 파일 | 과목 | 학습 방식 |
| --- | --- | --- |
| `index.html` | 첫 화면 + 문학(고전시가) | 원문을 구절 단위로 넘기며 해석 |
| `edu.html` | 교육학 | 이론명을 보고 내용을 떠올리는 인출 연습 |
| (준비 중) | 문법 | — |

두 앱은 파일이 분리되어 있어 한쪽을 고쳐도 다른 쪽에 영향이 없습니다. 학습 기록은 브라우저에 각각 다른 이름(`gjsg-progress`, `eduq_*`)으로 저장되므로 서로 겹치지 않습니다.

---

## 문학 · 고전시가 연습

고전시가 인터랙티브 학습 웹앱입니다. 갈래를 고르고 작품을 선택하면 원문을 한 구절(단락)씩 넘겨 보며, 해석은 탭해서 확인할 수 있습니다. 마지막 구절까지 넘기면 주제·표현상 특징·임용 대비 시사점을 정리한 요약 화면으로 넘어갑니다.

HTML/CSS/JavaScript로만 작성된 정적 웹앱이라, 별도 빌드 과정이나 서버 없이 바로 실행됩니다.

## 수록 내용

총 **59개 작품**, 7개 갈래:

| 갈래 | 작품 수 |
| --- | --- |
| 향가 | 9 |
| 고대가요 | 5 |
| 고려가요 | 10 |
| 경기체가 | 4 |
| 시조 | 18 |
| 가사 | 8 |
| 기타 (판소리·잡가 등) | 5 |

원문·현대어역·작품 해설은 직접 정리해 둔 hwp 자료를 1차 출처로 삼아 작성했습니다.

## 기능

- **갈래별 학습**: 갈래 선택 → 작품 목록 → 원문을 구절 단위 카드로 넘기며 학습
- **해석 보기**: 카드를 탭하면 원문 ↔ 현대어역이 전환됩니다 (구절에 따라 원문만 있는 경우도 있음)
- **작품 요약**: 학습을 마치면 주제 · 표현상 특징 · 임용 대비 시사점을 정리해 보여줍니다
- **진행 기록**: 완료한 작품은 브라우저의 `localStorage`에 저장되어 목록에 체크 표시됩니다 (브라우저·기기별로 별도 저장됨)
- **랜덤 구절뽑기**: 전체 작품의 모든 구절 중 하나를 무작위로 뽑아 복습할 수 있습니다. 뽑힌 구절은 탭해서 해석을 확인하고, `해설` · `전문보기` · `다음 🎲` 세 가지 버튼으로 해당 작품의 해설을 보거나 전체 맥락을 확인하거나 새로 뽑을 수 있습니다

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다. 두 파일(`index.html`, `edu.html`)은 반드시 같은 폴더에 두어야 과목 간 이동이 됩니다.

### GitHub Pages로 배포하기

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 **Settings → Pages**에서 배포 브랜치(예: `main`)와 루트 폴더를 지정합니다.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.

## 구조

모든 작품 데이터는 `index.html` 안의 `WORKS` 배열에 다음과 같은 형태로 들어 있습니다.

```js
{
  id: 'gwandongbyeolgok',
  genre: '가사',
  title: '관동별곡',
  author: '정철',
  era: '조선 중기',
  lines: [
    { orig: '원문...', trans: '현대어역...' },
    // ...
  ],
  summary: {
    theme: '주제...',
    features: ['표현상 특징...'],
    examPoints: ['임용 대비 시사점...']
  }
}
```

새 작품을 추가하거나 기존 작품을 수정하려면 이 배열에 항목을 더하거나 고치면 됩니다. `orig`만 있고 `trans`가 없는 구절은 해석 보기 버튼 없이 원문이 그대로 표시됩니다(원문 자체가 이미 현대어에 가깝거나, 신뢰할 수 있는 현대어역을 아직 확보하지 못한 경우).
